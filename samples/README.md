# Sample images

29 road/traffic photos for testing the quality checker locally — highways,
rural roads, traffic jams, intersections, night/rain/fog conditions, and a
few autonomous-vehicle shots. All sourced from Wikimedia Commons under
open licenses (CC0, Public Domain, CC BY, or CC BY-SA). Downloaded as
~900px-wide thumbnails to keep the repo small.
